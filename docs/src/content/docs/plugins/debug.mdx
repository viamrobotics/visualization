---
title: <Debug />
description: Mount the TanStack Query devtools panel inside a Viam visualizer.
---

`<Debug />` surfaces the [TanStack Query devtools](https://tanstack.com/query/latest/docs/framework/svelte/devtools) panel — inspect the query cache, view in-flight mutations, and refetch manually — for any visualizer instance. The visualizer issues its Viam RPC calls through `@viamrobotics/svelte-sdk` (built on TanStack Query), so the devtools attaches to the `QueryClient` your `<ViamAppProvider>` already sets up. No extra wiring required.

The devtools package is an **optional peer dependency** — it isn't bundled with Viam Visualization, so consumers that don't mount `<Debug />` pay nothing for it.

## Install

```bash
pnpm add -D @tanstack/svelte-query-devtools
```

## Usage

Mount `<Debug />` anywhere inside `<Visualizer />`:

```svelte
<script lang="ts">
	import { Visualizer } from '@viamrobotics/visualization'
	import { Debug } from '@viamrobotics/visualization/plugins'
</script>

<div class="h-screen w-screen">
	<Visualizer>
		<Debug />
	</Visualizer>
</div>
```

A floating TanStack logo appears in the bottom-left corner of the viewport — click it to open the devtools panel. Unmount the component (or remove it from the tree) to hide both the button and the panel.
